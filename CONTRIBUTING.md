# Contributing to SYCRO VALDOVINOS

1. Crea una rama: `git checkout -b feature/nombre`
2. Instala dependencias.
3. Ejecuta las pruebas y el build.
4. No agregues secretos, claves privadas ni archivos `.env`.
5. Abre un Pull Request.

**Nota:** No se aceptan nuevos algoritmos criptográficos sin revisión previa.
